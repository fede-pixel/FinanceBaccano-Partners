Al primo import dello storico indica la data da cui partire: le scadenze precedenti vengono considerate già pagate e non sporcano il forecast.

Come esportare da Aruba

Dal pannello di Aruba Fatturazione Elettronica seleziona le fatture (emesse o ricevute) e scarica i file XML (o un archivio ZIP). Puoi caricare qui anche i file firmati .p7m.

Va bene anche il report Excel di Aruba (ReportFattureRicevute.xls / ReportFattureEmesse.xls): una riga per fattura. Le fatture segnate "Pagata" o pagate con carta o contanti risultano già saldate; le autofatture per servizi esteri (TD17, TD18…) vengono archiviate senza uscita prevista, perché il pagamento è già nei movimenti della carta. Le fatture già importate come XML non vengono duplicate.

Se la fattura non indica la data di scadenza, l'app la stima a 30 giorni dalla data fattura (valore modificabile nelle Impostazioni) e la segna come "stimata".

In una fase successiva potremo collegare direttamente le API di Aruba, così le fatture arrivano da sole.
